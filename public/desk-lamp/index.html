Stage 08 · Flexible Physics & Cycles Metal Animation

Stretching Helical Springs & Flexing Braided Cords in Motion

Standard rigid-body CAD rigs distort spring wire cross-sections when scaled and detach cables at moving joints. In Blender 5.2 LTS (Cycles Metal GPU), we authored a frame-driven procedural solver (desk_lamp_anglepoise_noir_v4_flex_anim.blend) that regenerates all four constant-wire-diameter helical springs and all three constant-arc-length braided cord loops live on every frame.

3. Establishing Live Connections Across DCC & CAD Applications MCP JSON-RPC · Headless Python · API Bundles

Because Blender, FreeCAD, and Autodesk Fusion 360 each expose completely different automation surfaces on macOS, we established three tailored integration bridges rather than forcing brittle GUI automation:

Bridge 01 · Live MCP Antigravity ↔ Blender 5.2 Configured mcp_config.json pointing to blender-mcp. Connected to Blender's live add-on socket for interactive Python execution, camera switching, and visual render feedback loops.
Bridge 02 · Headless CLI Shell → Blender & FreeCAD Batch renders run via Blender --background; FreeCAD B-Rep builds and HLR drawings execute via FreeCAD's bundled bin/python with Resources/lib on sys.path and QT_QPA_PLATFORM=offscreen.
Bridge 03 · Native API Workspace → Fusion 360 Verified running Fusion 360 process and deployed self-contained Python + .manifest bundles directly into Fusion's local API/Scripts/ directory for one-click execution in Utilities → Scripts & Add-Ins.
Bridge 04 · Single Truth Shared JSON Schema lamp_cad_params.json synchronizes identical millimeters, kinematic angles, spring specs, and material densities across Blender, FreeCAD, Fusion 360, and the ISO A3 drawing generator.
4. Real Technical Blockers Encountered & Exact Fixes Undertaken 8 Root-Cause Engineering Resolutions

Getting three distinct 3D/CAD kernels to interoperate cleanly required diagnosing and resolving real API quirks, kernel bottlenecks, and physical defects along the way:

1. Fusion 360 Read-Only Root Component RuntimeError: 3 : root component name cannot be changed aborted initial native script startup on line 540.
Fix Applied Removed direct assignment to design.rootComponent.name; structured all 9 sub-assemblies cleanly as named child occurrences under root while keeping document naming managed by Fusion.
2. Fusion 360 Revolve & Crown Vent Cut Failure RuntimeError: 3 : No target body found to cut or intersect occurred when cutting the 8 crown vents into the spun bell shade.
Fix Applied Added explicit setAngleExtent("360 deg") on all Revolve features and corrected the inner shade profile spline sign (s - wt_sh → s + wt_sh) so the spun wall formed a closed manifold solid before cutting.
3. Kinematic Inversion & Erratic Dragging in Fusion 360 Dragging the shade interactively caused the upper/lower arms to flip 180° through the base frustum because unconstrained Revolute Joints allowed full 360° inversion.
Fix Applied Added explicit mechanical rotationLimits (minimum/maximum angular stops) to all 8 Revolute Joints and created DeskLamp_Animate_Fusion.py for deterministic cosine-eased motion playback.
4. FreeCAD freecadcmd -c & Headless Qt Abort Multi-line freecadcmd -c invocations and importing PySide6.QtGui without an active macOS window server crashed with Application unexpectedly terminated.
Fix Applied Switched execution to FreeCAD's bundled /Applications/FreeCAD.app/Contents/Resources/bin/python with QT_QPA_PLATFORM=offscreen and Resources/lib prepended to sys.path—unlocking stable headless OCCT + native vector PDF/PNG export without external Inkscape/rsvg dependencies.
5. OpenCASCADE HLR Stall on 248 Helical B-Spline Turns Running TechDraw.projectEx directly on all 4 swept 3D helical springs triggered an O(N²) B-Spline visibility bottleneck (>40 s per view) and merged 1 mm wire strokes into solid smudges at 1:3 scale.
Fix Applied Preserved all 4 exact 3D swept helical B-Rep solids inside desk_lamp_exploded_assembly.FCStd and mass calculations, while projecting crisp ISO 2162 helical coil schematics directly from exact 3D anchor points in 2D SVG—cutting full 2-sheet generation time to ~15 seconds with razor-sharp drafting clarity.
6. Part.Compound Missing .CenterOfMass Multi-solid grouped BOM assemblies (e.g., 4× EPDM feet or paired arm tubes) threw attribute errors when computing centroid anchors for balloon leaders.
Fix Applied Implemented volume-weighted centroid integration across shape.Solids and selected the camera-facing -Y solid centroid for symmetric pairs so every exploded balloon points cleanly to the visible foreground member.
7. Mechanical Clash Audit Defects (v1 → v2) Early mechanical review caught top-clipping wrist tabs, floating trunnions, and a central tie-rod interference against the A1 spring pin.
Fix Applied Engineered the straddling wishbone shade U-yoke, shifted the tie-rod rearwards to X = -12 mm through split cantilevered A1/A2 pins (18 mm open center window), and verified 11/11 zero-interference B-Rep clash checks.
8. Realistic Flexible Springs & Cords During Motion Non-uniform scaling of static spring meshes flattens circular wire into ovals and stretches hooks off pins; static cords detach from moving grommets during articulation.
Fix Applied Authored a live frame_change_pre Blender driver using rigid anchor empties to regenerate 3D beveled constant-wire-diameter helices (rigid circular hooks + uniform pitch expansion) and an 8-step bisection Bezier solver maintaining constant cord length and grommet exit tangency across all 240 Cycles frames.
